# Pawloc 🐾

## About the Project

**Pawloc** is a web-based Lost and Found Pet Management System designed to help pet owners, rescuers, shelters, and community members report lost or found pets and improve the process of reuniting pets with their owners.

Instead of relying on scattered social media posts and physical flyers, Pawloc provides a centralized platform where pet reports can be organized, searched, and updated more easily.

## Features

- User registration and login
- Report lost or found pets
- Upload pet photos and descriptions
- Add last-seen or found locations
- Search and filter pet reports
- Update pet report status
- Shelter and rescuer management
- Secure storage of pet information
- Location-based mapping

## Technologies Used

- React.js
- Vite
- Supabase
- PostgreSQL
- HTML
- CSS
- JavaScript
- Web Mapping API

## Getting Started

### 1. Clone the Repository

```bash
git clone YOUR-GITHUB-REPOSITORY-URL
```

### 2. Open the Project Folder

```bash
cd Pawloc
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the root folder:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 5. Run the Project

```bash
npm run dev
```

Open the local URL displayed in the terminal, usually:

```text
http://localhost:5173
```
